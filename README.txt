МОЯ ВОДА — первая версия

Файлы:
- index.html — приложение
- manifest.json — настройки установки на главный экран
- sw.js — базовое кеширование для офлайн-открытия

Как проверить:
1. Открой index.html в браузере. Добавления, цель, история и статистика сохраняются в браузере на этом устройстве.
2. Чтобы установить как веб-приложение и включить service worker, размести все файлы на HTTPS-хостинге (например, GitHub Pages).
3. Напоминания в этой версии работают, пока приложение открыто. Полноценные фоновые push-уведомления требуют отдельного push-сервера.

Данные хранятся локально в браузере устройства. Очистка данных сайта может удалить историю.
